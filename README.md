


# 🚀 OSPF Configuration – 4-Router Network (Cisco Packet Tracer)

Welcome to my **Networking Lab Project** where I set up and configured a fully functional **4-router OSPF network topology** using Cisco Packet Tracer! This project demonstrates how dynamic routing brings networks to life with **OSPF (Open Shortest Path First)** — a powerful link-state routing protocol.

---

## 🌐 Project Overview

🔧 **Goal**: Establish dynamic routing with OSPF across four interconnected routers.  
📡 **Tool**: Cisco Packet Tracer  
📘 **Concepts Covered**:  
- Multi-router OSPF setup  
- IP addressing  
- Routing table verification  
- Connectivity testing  
- Neighbor relationship validation  

---



## ⚙️ Key Features

✨ Clean 4-router design  
📍 IP address planning included  
🧠 OSPF Area 0 configuration  
📊 Verified with `ping`, `show ip route`, and `show ip ospf neighbor`  
💡 Educational & beginner-friendly  



## ▶️ How to Run

1. Download and open the `.pkt` file in Cisco Packet Tracer (v7.2 or later).
2. Click each router to explore its CLI.
3. Use `ping` to test connectivity across the network.
4. Run `show ip route` and `show ip ospf neighbor` to explore OSPF in action.

---

## 🧠 Learning Outcomes

By exploring this project, you’ll understand:
- How to enable and verify OSPF
- How routers exchange routing information
- How link-state protocols maintain updated topologies
